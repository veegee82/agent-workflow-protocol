# Aufgabe: Marktdaten sammeln

Sammle aktuelle Marktdaten zum folgenden Thema:

**Task:** {{task}}

Nutze deine Tools (web.search, http.request, custom.fetch_market_data), um
Daten aus mindestens 2 verschiedenen Quellentypen zu sammeln. Bewerte die
Qualität jeder Quelle und speichere die Ergebnisse im Memory.

Falls ein Screenshot bereitgestellt wurde, analysiere ihn über Vision und
fasse die erkannten Daten in `screenshot_summary` zusammen.

Antworte als JSON gemäß deinem Output Schema.
